# コンテンツの確認・修正事項

## 外部リンク

[外部リンクの確認待ち一覧](EXTERNAL_LINK_TODO.csv)に、対象URL、現在の編集元、置換候補、次の対応を記載しています。状態は最終確認日時点の情報です。修正時にリンク先を開き、目的の記事・資料かを確かめてください。

置換候補があるURLは、編集元で差し替えて掲載ページから確認します。移転先が不明な場合は、記事・イベント・論文名から公開先や保存版を探します。見つからなければ説明文を残してリンクを外せます。

認証要求やアクセス制限、タイムアウトになったURLは、通常のブラウザーで本文を確認してください。DOIは論文タイトルと登録先を照合します。

修正・確認が済んだ行は一覧から削除してください。ビルド後のプレビューで英日両方の掲載ページとリンク先を確認します。

[people-are-programmers第3章](../site/talks/people-are-programmers.tsx)は、次の操作を説明文とTextAliveへのリンクで案内しています。ページ内で操作する機能は未実装です。

| 対象     | 操作                                                      |
| -------- | --------------------------------------------------------- |
| `#tapl1` | 0〜15000msを指定し、`v = f(t)` で動画のフレームを描画する |
| `#tapl2` | 花びらの枚数を3〜30枚に変更する。初期値は5枚              |
